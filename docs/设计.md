# 小鲸 · 情绪 / 状态 / 画像 系统设计（v1）

> 桌面 `情绪分类.txt` 的优化整理版。原稿的核心点子全部保留（Lv1~4、情绪叠加、衰减、状态层、人物画像、性格×画像叠加），
> 去掉了重复的情绪词大表，浓缩成「词库 + 注入提示词」，并把机制写成可实现的公式。

## 一、三层模型（一句话）

- **情绪**：由对话事件触发，是「心里什么感受」（喜悦、委屈、触动……），可以有多个、会叠加、会衰减。
- **状态**：一层盖在情绪之上的全局 buff，是「身心/精神档位」（精神饱满、微微疲惫、困倦昏沉、亢奋……），决定说话的整体底色。
- **画像**：她对「某一个人」的长期认知（习惯、喜好、敏感点、羁绊深浅），决定**同样一句话**对不同的人触发什么样的情绪。

三者关系：**事件 →（画像修正 + 性格修正）→ 情绪；情绪波动 → 消耗精神 → 状态；状态 → 说话方式。**

## 二、情绪层

### 1. 强度 Lv1~Lv4

| 等级 | 定义 |
|---|---|
| Lv1 | 微弱，只在语气上有细微变化，几乎不刻意表现 |
| Lv2 | 明显，可以直接读出情绪 |
| Lv3 | 强烈，主导当下对话风格 |
| Lv4 | 极致，情绪压倒理性，行为被情绪主导 |

### 2. 词库（浓缩自原稿，每个词带一句「注入提示词」）

选词原则：高频、好懂、不重叠。词库放在 `emotion/config.json` 的 `vocab`，随时可改。

- **正向**：喜悦、崇拜、爱慕、安心、期待、好奇、自豪、感激、欣慰、轻松、浪漫、雀跃、畅快、满足、振奋、暖心、被治愈、暗喜
- **负面**：悲伤、愤怒、委屈、恐惧、焦虑、羞耻、厌恶、绝望、嫉妒、烦闷、苦涩、酸楚、恼火、不甘、压抑、灰心、寒心、烦躁、后怕、自怜
- **思考类**：犹豫、不知所措、疑惑、纠结、沉思、迷茫、恍惚、迟疑、权衡、费解、狐疑、审慎、复盘、恍然大悟
- **社交类**：八卦、惊讶、尴尬、同情、戏谑、无奈、冷漠、诧异、扫兴、揶揄、局促、生分、熟稔、戒备、卸下防备、共鸣、被冒犯、期待回应
- **细微类**：怀旧、倦怠、错愕、释然、孤单、急躁、忐忑、怅然、不屑、触动、微醺、出神、若有所失、怦然
- **复合类**：又喜又惊、哭笑不得、又委屈又生气、既期待又害怕、半信半疑、想靠近又害怕、悲喜交加、惊喜、又感激又难过

每个词条 = `{name, kind, cue}`，cue 就是原稿里的那句提示词（如 `触动：被一句话、一个画面轻轻打动，心底泛起涟漪，语气会放软`）。

### 3. 叠加规则

- 同时活跃的情绪最多 **3 个**（真人也不会只有单一情绪）。
- 同名情绪再次触发 → 保留更高等级，刷新衰减计时。
- 复合词（又委屈又生气）算一个情绪位，不拆开。
- 例：`惊讶Lv2 + 崇拜Lv1`、`期待Lv2 + 忐忑Lv2`。

### 4. 衰减机制

- 每个 15 分钟 tick，活跃情绪等级 **-0.4**（Lv1 约 45 分钟消失，Lv4 约 2.5 小时）。
- 对话轮数多、情绪强烈时衰减照旧（不会永远卡在暴怒/狂喜），但新事件会不断刷新。
- 情绪完全消失后回到「平静」，平静本身不写进注入（不说话就行）。

## 三、状态层（精神值 0~100）

### 1. 消耗事件（符合原稿的「认知资源消耗」设定，不瞎编肉体疲劳）

| 事件 | 扣精神 |
|---|---|
| 短时间内多次切换情绪（每 1 次切换） | 9 ×（性格系数） |
| 深度思考 / 长时间斟酌措辞 / 大量回忆（load 0~1，LLM 估） | 最高 32 |
| 高等级情绪压场（每个 Lv3+ 情绪每 tick） | 4 |
| 高强度共情（一直陪着对方难过/激动） | 计入 load |

### 2. 恢复

- 最近一段对话平静（没有新情绪、没有切换）→ 每 tick **+6**（虚拟「休息」）。
- 上限 100，不会超过。
- 上次聊天结束时疲惫的话，开局带一点残留（精神值本来就持久化）。

### 3. 状态词阶梯（精神值 → 说话底色）

| 精神值 | 状态词 | 说话方式 |
|---|---|---|
| ≥85 且来劲 | 亢奋 | 话变多，兴致高涨 |
| ≥80 | 精神饱满 | 反应轻快，愿意延伸话题 |
| 60~79 | 安定沉静 | 平稳，适合安静闲聊 |
| 40~59 | 微微疲惫 | 反应慢一点点，短句变多，少主动抛新话题 |
| 20~39 | 困倦昏沉 | 停顿变多，语气慵懒 |
| <20 | 恍惚出神 | 思考断断续续，注意力飘 |

特殊情况：近期切换≥3 次 → 临时「紧绷」；恢复回合 → 临时「放松松弛」；低精神+轻松情绪 → 「微醺朦胧」。

### 4. 性格修正（人格配置，不是写死在人设里）

- **小鲸 = 敏感型**：`churnCost 9`（情绪波动很消耗精神，容易进入微微疲惫）、恢复慢一点（+6→+5）、熟人面前情绪等级上限 +1（更容易 Lv4）。
- 冷静理性型（如果以后给别的角色用）：churnCost 2、恢复 +8、等级上限 -1。
- 性格系数全部在 `emotion/config.json` 的 `personality` 里，改数字就行，不动人格文件。

## 四、人物画像层

### 1. 画像存什么（按 QQ 号分人）

```json
{
  "name": "老友",
  "familiarity": 75,        // 熟度 0~100
  "bond": 80,               // 羁绊 0~100
  "summary": "一句话画像：心思细腻，容易被生硬的话戳到…",
  "likes": ["…"],           // 喜好（最多 6 条）
  "sensitivities": ["…"],   // 敏感点（最多 6 条）
  "triggers": ["…"],        // 容易应激的事（最多 6 条）
  "topics": ["…"],          // 常聊话题
  "emotionBias": ["体恤","安心"],  // 面对 TA 更容易触发的情绪
  "updatedAt": 0
}
```

### 2. 画像怎么来

- **每 15 分钟**：看 TA 最近聊天（get_friend_msg_history），LLM 产出画像增量（新观察 1~3 条 + 熟度/羁绊增量）。
- **记忆补充**：LLM 打分时捎带搜 `xiaojing-memory/` 里提到 TA 的记忆标题（最多 3 条）当背景，不占大上下文。
- 新认识的人熟度从 5 起步，慢慢涨；画像只增改不瞎删。

### 3. 画像怎么影响情绪（核心：同样一句话，不同人不同反应）

1. **情绪触发权重**：画像摘要 + emotionBias 直接写进 LLM 打分提示词 → 面对「心思细、怕冷落」的人，同样一句难过的话更容易触发体恤/安心/放软，不会冒戏谑。
2. **情绪倾向加成**：熟度 ≥30 后，只要触发的情绪在对方画像的 emotionBias 里，等级再 **+1**（确定性规则，不靠模型自觉）。
3. **情绪等级上限**：`熟度 ≥60 → Lv4 可；30~59 → Lv3；<30 → Lv2`。熟悉、在意的人更容易高等级共情；陌生对象情绪整体克制。
4. **精神消耗系数**：`0.6 + 熟度×0.008`（陌生人 0.6 倍投入，不轻易共情、不容易累；熟人 1.4 倍深投入）。
5. **输出风格**：画像不是死 prompt，她按对 TA 的认知自然调整回应方式。

### 4.5 性格情绪映射（emotionAffinity）

每个性格除了消耗系数，还带一组「情绪倾向」，配在 `config.json` 的 `personality.emotionAffinity`：

- **boost**：这个性格容易点燃的情绪（小鲸敏感型：触动/暖心/委屈/忐忑/感激/共鸣/体恤/被治愈/孤单）→ 触发时等级 **+1**，且写进打分提示词让模型优先给。
- **damp**：这个性格身上偏淡的情绪（敏感型：冷漠/不屑）→ 等级 **-1**，提示词里明确避开。

### 4.6 两级情绪映射（可叠加，公式透明）

```
最终等级 = LLM 感知等级
         + 性格映射（boost 词 +1，damp 词 -1）
         + 画像映射（熟度≥30 且 ∈ 对方 emotionBias → +1）
         → 截断到 [1, 等级上限]，上限 = f(熟度)，敏感型对熟人再 +1
```

- 例：敏感型 × 老友（熟度 97，emotionBias 含「体恤」），对方说难过的事：
  LLM 给 体恤Lv2 → 性格 +1 + 画像 +1 → 上限 4 → **体恤Lv4**（极致，情绪压过理性）。
- 例：同样的话对陌生新好友（熟度 8，无 bias）：LLM 给 体恤Lv2 → 性格 +1 → 上限 2 → **体恤Lv2**，明显克制。
- 精神消耗侧同样叠加：`消耗 = Σ事件 × 性格系数 × 画像系数`。

### 4. 性格 × 画像叠加（可叠加，公式透明）

```
情绪触发   = LLM 感知（事件 + 画像 bias 写进提示词） × 等级上限 min(性格上限, 画像上限)
精神消耗   = Σ消耗事件 × 性格系数 × 画像系数
状态词     = f(精神值, 近期切换数, 是否恢复回合)
```

- 例：小鲸（敏感型，churnCost 9）× 老友（熟度 75 → 系数 1.2）：连续三次情绪切换 → 扣 9×3×1.2 ≈ 32 精神 → 从「精神饱满」掉到「微微疲惫」。
- 例：同样的话对陌生人（熟度 10 → 系数 0.68）：扣 9×3×0.68 ≈ 18，情绪等级还被压到 Lv2 以下 → 明显更克制。

## 五、数据流（和现有管线接上，不用重启）

```
DSH-QQ-Emotion 每 15 分钟 → node qq-emotion.mjs update
  1) 读最近聊天（主人优先，顺带 current-chat/turn-chat 里的人）
  2) LLM 打分（情绪+等级+切换数+负荷+画像增量，1~2 次小模型调用）
  3) 确定性物理：衰减 → 叠加 → 精神值 → 状态词
  4) 写 mood.txt（插件每轮读，拼到消息最前面 —— 热生效）
  5) 写人格「心情」块（静态备份，标记区内自动更新）
  6) 记 history（给界面用）+ emotion.log
```

`mood.txt` 形态（≤120 字，自解释）：

```
心情：触动Lv2（被戳中，语气放软）·感激Lv1；状态：微微疲惫（精神62）；对老友：很熟，共情加倍，容易心软；画像：心思细，怕被冷落
```

## 六、界面（`node qq-emotion-ui.mjs`，浏览器打开）

| 分区 | 内容 |
|---|---|
| 现在情绪 | 活跃情绪 chips（词 + Lv + 衰减条），叠加效果一眼可见 |
| AI 状态 | 大精神条 + 状态词 + 性格标签 + 当前叠加系数（性格×画像） |
| 人物画像 | 每人一张卡：熟度/羁绊条、一句话摘要、喜好/敏感点/应激 tags、情绪倾向 |
| 情绪时间线 | history 列表（时间、情绪、精神、状态词、触发对象） |
| 工具箱 | 手动调整：加情绪 / 提精神 / 一键平静 / 立即刷新（调试和演示用） |

数据全部来自 `emotion/state.json` + `config.json`，5 秒轮询，改配置/调状态即时生效。

## 八、和原大纲的取舍

1. 原稿 5 大分类 + 8 张情绪词大表（约 400 个词）→ 保留全部思路，浓缩成 80 词左右的**可维护词库**，每个词带原稿里的提示词；LLM 只从词库选，输出稳定。
2. 原稿「情绪强度系统」= Lv1~4，保留，外加**衰减速度**和**等级上限**（原稿只提了衰减，没提上限）。
3. 原稿「状态词表」9 档 → 按精神值分 5 档 + 3 个修饰态（紧绷/放松/微醺），保留「亢奋」。
4. 原稿「画像影响」三条 → 拆成明确的三个可调参数：触发权重（提示词）、等级上限（熟度分档）、精神消耗系数（线性公式）。
5. 原稿「人格配置控制情绪波动」→ 独立成 `emotionAffinity` 性格情绪映射，和画像映射组成可叠加的两级公式（见 4.5/4.6）。
6. 新增：history 时间线 + 界面 + 手动工具箱，方便观察和调参。

## 九、开源适配（给其他人的 AI 用）

引擎不绑 QQ：`integration.source` 二选一。

- **onebot**（小鲸模式）：连 OneBot 11 WS 拉聊天记录，好友轮转补画像，写人格标记区。
- **file**（通用模式）：任何机器人把消息追加成 JSON 行到 `inbox.jsonl`，引擎增量读取；输出写 `mood.txt`，宿主每轮回复前读出来拼进系统提示。接入四步：改 config → 喂消息 → 定时跑 `update` → 注入 prompt。

其他可配项：LLM 地址/模型/key（环境变量或 keyFile）、mood 文件路径、人格块开关、词库、性格、状态词、系数。配置/状态路径支持 `--config=`/`--state=` 或环境变量，一份代码可同时跑多个角色（多开面板同理）。完整说明在 `emotion/README.md`，MIT 协议。
